# LLM Adapter Service

## Описание

LLM Adapter Service отвечает за взаимодействие с внешней языковой моделью.

Сервис получает сообщение пользователя, запрашивает историю переписки через Storage Service, формирует контекст диалога и отправляет запрос в LLM.

После получения ответа сервис сохраняет его в Storage Service и возвращает результат в Chat Service.

---

## Основные функции

- получение истории переписки;
- формирование контекста;
- добавление системного промпта;
- отправка запроса в LLM;
- получение ответа модели;
- сохранение ответа.

---

## Архитектура

```
Chat Service
      │
      ▼
LLM Adapter Service
      │
      ▼
Storage Service
      │
      ▼
 PostgreSQL

LLM Adapter Service
      │
      ▼
CometAPI / OpenAI API
```

---

## Последовательность работы

1. Получение сообщения.
2. Запрос истории переписки.
3. Формирование массива сообщений.
4. Отправка запроса в LLM.
5. Получение ответа.
6. Сохранение ответа.
7. Возврат результата.
